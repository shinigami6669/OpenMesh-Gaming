## 📖 معرفی پروژه

**OpenMesh Gaming** یک مجموعهٔ متن‌باز و آمادهٔ بهره‌برداری از شبکه مش همتا‌به‌همتا (P2P) است که برای گیمینگ چندنفره با تأخیر پایین، شبیه‌سازی شبکه محلی (LAN) و شبکه‌های مقاوم در برابر اختلال طراحی شده است.

راه‌حل‌های سنتی مانند Hamachi، Radmin VPN یا ZeroTier Cloud به‌شدت به سرورهای ابری خارجی وابسته‌اند. وقتی پینگ بالا، ازدحام شبکه یا فایروال‌های سخت‌گیرانه باعث قطع اتصال می‌شود، جلسهٔ بازی شما از بین می‌رود.

**OpenMesh Gaming تمام وابستگی‌های ابری شخص ثالث را حذف می‌کند**:
- سرور لینوکس شما (مثلاً رزبری پای) نقش **Network Controller مستقل** و **Custom Moon Root Node** را بر عهده می‌گیرد.
- بازیکنان مستقیماً و از طریق UDP hole punching به یکدیگر متصل می‌شوند.
- ترافیک شبکهٔ محلی با سرعت سیمی و تأخیر ۰ تا ۱ میلی‌ثانیه جریان دارد، در حالی که دوستانی که از طریق اینترنت و پورت‌ فوروارد روتر وصل می‌شوند، اتصال مستقیم و پایدار خواهند داشت.

## ✨ ویژگی‌ها

- **🚀 نصب‌کنندهٔ لینوکسی با یک کلیک (`install.sh`):**
  - نصب کاملاً خودکار روی Raspberry Pi OS، دبیان، اوبونتو و لینوکس مینت.
  - راه‌اندازی دیمن کنترلر ZeroTier، تخصیص بازهٔ IP قابل تنظیم، ساخت Moon امضاشده و ثبت سرویس `systemd`.
  - **کاملاً پارامتری‌شونده:** زیرشبکهٔ mesh، IP مجازی سرور، اطلاعات ادمین، پورت داشبورد و IP عمومی همگی هنگام نصب قابل تعیین هستند.
- **🛡️ ۱۰۰٪ مستقل و آمادهٔ کار آفلاین:**
  - روی شبکه‌های محلی ایزوله (بدون نیاز به اینترنت) نیز به‌طور کامل کار می‌کند.
  - هم‌زمان از بازیکنان راه دور روی اینترنت از طریق IP ثابت یا DDNS پشتیبانی می‌کند.
- **🎛️ داشبورد وب با ظاهر Cyber Dark:**
  - رابط کاربری HTML5 مدرن و واکنش‌گرا (بدون Node.js یا فریم‌ورک سنگین؛ کاملاً با پایتون ۳ خالص).
  - جدول بازیکنان متصل به‌صورت بلادرنگ با دکمهٔ کپی IP، نشانگر پینگ و وضعیت آنلاین.
  - **تفکیک Kick از Ban:** بازیکن را فقط از جلسهٔ فعلی خارج کنید (Kick) یا به‌طور دائمی مسدود کنید (Ban) — تنها با یک کلیک.
  - پنجرهٔ بازتولید خودکار Moon با هم‌زیستی نقاط انتهایی LAN و WAN.
  - دستیار داخلی برای پورت‌فوروارد روتر.
- **🖥️ کلاینت ویندوزی C# با یک کلیک:**
  - پشتیبانی از چند تم (**Cyber Dark**، **Cyberpunk Purple** و **Clean Light**).
  - **رابط دوزبانه** با امکان تعویض لحظه‌ای زبان بین **انگلیسی** و **فارسی**.
  - **دکمهٔ لغو/قطع اتصال فوری** که به بازیکن اجازه می‌دهد هر لحظه عملیات اتصال را بدون قفل‌شدن برنامه متوقف کند.
  - نمایش زندهٔ پینگ برای سرور مرکزی، هاست/پیر و IP مجازی تخصیص‌یافته.
  - شناسایی خودکار سرور در زیرشبکه‌های محلی یا اتصال از طریق IP/دامنهٔ عمومی تنظیم‌شده.
  - دانلود و همگام‌سازی خودکار فایل Moon امضاشدهٔ سرور، بدون پیکربندی دستی.
  - کامپایل در چند ثانیه با کامپایلر داخلی C# ویندوز (`csc.exe`).

## 🚀 سناریوهای راه‌اندازی سرور

سناریویی را انتخاب کنید که با محیط استقرار شما مطابقت دارد.

---

### 🏠 سناریوی الف: دستگاه شخصی در خانه (رزبری پای، مینی‌کامپیوتر یا PC لینوکسی)

اگر سرور را روی دستگاهی متصل به روتر/وای‌فای خانگی اجرا می‌کنید:

* **مزایا:** بازیکنانی که روی همان وای‌فای یا اینترنت هستند، با تأخیر **کمتر از ۱ میلی‌ثانیه** و سرعت سیمی بازی می‌کنند و مالکیت کامل سخت‌افزار در اختیار خودتان می‌ماند.
* **پیش‌نیازها برای دوستان اینترنتی:**
  1. **IP ثابت عمومی یا DDNS:** از ISP خود IP ثابت بگیرید یا از سرویس DDNS رایگان (مثلاً DuckDNS) استفاده کنید.
  2. **پورت‌ فوروارد روتر:** این دو پورت را در روتر خانگی به IP محلی سرور (مثلاً `192.168.1.100`) فوروارد کنید:
     - **`9993`** (**UDP**) ➔ ترافیک ZeroTier Mesh و Moon Root
     - **`8080`** (**TCP**) ➔ داشبورد وب و هندشیک کلاینت
     *(راهنمای گام‌به‌گام در [docs/PORT_FORWARDING.md](docs/PORT_FORWARDING.md) آمده است).*
* **نصب:**
  ```bash
  git clone https://github.com/shinigami6669/OpenMesh-Gaming.git
  cd OpenMesh-Gaming/server
  sudo chmod +x *.sh
  sudo ./install.sh
  ```
  *(نصب‌کننده از شما زیرشبکهٔ mesh، IP مجازی سرور، اطلاعات ادمین و در صورت نیاز IP عمومی مودم را می‌پرسد.)*

---

### ☁️ سناریوی ب: سرور ابری / اختصاصی (Hetzner، DigitalOcean، AWS و ...)

اگر سرور را روی یک ماشین مجازی اینترنتی اجرا می‌کنید:

* **مزایا:** **بدون هیچ پیکربندی روتر و بدون پورت‌فوروارد!** سرور از پیش IP عمومی مستقیم، آپ‌تایم ۲۴ ساعته و پهنای باند پرسرعت دیتاسنتر دارد و همهٔ دوستان از هرجایی می‌توانند وصل شوند.
* **پیش‌نیازها:**
  1. فقط پورت‌ها را در فایروال لینوکس (UFW) یا گروه امنیتی ابر باز کنید:
     ```bash
     sudo ufw allow 22/tcp
     sudo ufw allow 8080/tcp
     sudo ufw allow 9993/udp
     sudo ufw enable
     ```
* **نصب:**
  ```bash
  git clone https://github.com/shinigami6669/OpenMesh-Gaming.git
  cd OpenMesh-Gaming/server
  sudo chmod +x *.sh
  sudo ./install.sh
  ```
  *(هنگام پرسش، IP عمومی VPS را وارد کنید.)*

### ⚙️ مدیریت سرور و به‌روزرسانی با یک کلیک

بررسی وضعیت یا ری‌استارت سرویس:
```bash
sudo systemctl status openmesh-server
sudo systemctl restart openmesh-server
```

به‌روزرسانی سرور به آخرین نسخه در یک ثانیه:
```bash
cd OpenMesh-Gaming/server
sudo ./update.sh
```

### ۳. راه‌اندازی کلاینت ویندوز

<p align="center">
  <img src="docs/assets/demo.gif" alt="نمایش زندهٔ کلاینت OpenMesh Gaming" width="90%">
</p>

#### گزینهٔ الف: کامپایل با یک کلیک
نیازی به Visual Studio یا SDK خارجی نیست! کافی است اسکریپت ساخت را در پوشهٔ `client/` اجرا کنید:

```cmd
cd client
build.bat
```

این اسکریپت از کامپایلر داخلی C# ویندوز (`csc.exe`) استفاده می‌کند و `OpenMeshGaming.exe` را می‌سازد.

#### گزینهٔ ب: اجرا و اتصال
1. فایل `OpenMeshGaming.exe` را اجرا کنید (با دسترسی Administrator).
2. اگر روی همان وای‌فای محلی هستید، کلاینت سرور را **به‌صورت خودکار شناسایی می‌کند**.
3. اگر از بیرون اینترنت وصل می‌شوید:
   - روی دکمهٔ **`⚙️ تنظیمات`** در گوشهٔ بالا-راست کلیک کنید.
   - **IP ثابت عمومی یا دامنهٔ DDNS** هاست خود را وارد کنید.
   - **توکن Bootstrap** که نصب‌کننده چاپ کرده را در فیلد *Bootstrap Token* وارد کنید.
   - روی **Save Settings** کلیک کنید.
4. روی دکمهٔ **`CONNECT TO GAMING LAN`** کلیک کنید.
5. کلاینت فایل Moon سرور را دانلود می‌کند، به شبکه می‌پیوندد و IP مجازی بازی شما (مثلاً `10.147.20.xxx`) تخصیص می‌یابد.

> **توکن Bootstrap**
> نصب‌کننده یک **توکن Bootstrap** چاپ می‌کند و آن را در `server/config.json`
> با کلید `bootstrap_token` ذخیره می‌کند. کلاینت برای رسیدن به سرور *پیش از* پیوستن به
> مش به این توکن نیاز دارد: دانلود Moon root، استخراج Network ID و درخواست
> مجوزدهی روی کنترلر، همگی پیش از آنکه کلاینت آدرس مش داشته باشد انجام می‌شوند؛
> پس نمی‌توان دسترسی به آن‌ها را صرفاً به اعضای مش محدود کرد.
> این توکن فقط به همین سه مسیر دسترسی می‌دهد؛ سایر مسیرها (داشبورد، مدیریت اعضا،
> تنظیمات) همچنان به نام کاربری و رمز مدیر نیاز دارند.
>
> برای تغییر توکن، مقدار `bootstrap_token` را در `server/config.json` ویرایش و
> سرویس را ری‌استارت کنید.

## 🔒 امنیت و حریم خصوصی

- **بدون نشت داده:** این مخزن هیچ کلید خصوصی، رمز عبور، شناسهٔ نود یا آدرس IP شخصی هاردکد‌شده‌ای ندارد.
- **بدون رمز عبور هاردکد:** رمز داشبورد هنگام نصب تولید یا وارد می‌شود و در `/opt/openmesh/config.json` ذخیره می‌شود — هرگز در سورس کد.
- **هشدار رمز پیش‌فرض:** اگر داشبورد با رمز پیش‌فرض داخلی بالا بیاید، هنگام راه‌اندازی هشدار واضحی چاپ می‌کند. **پیش از باز کردن پورت 8080 روی اینترنت حتماً آن را تغییر دهید.**
- **بدون ردیابی ابری:** همهٔ تله‌متری، فهرست اعضا و کلیدهای شبکه صرفاً روی سخت‌افزار خودتان باقی می‌مانند.
- **نکتهٔ HTTPS:** داشبورد از HTTP Basic Auth استفاده می‌کند. برای انتشار روی اینترنت، آن را پشت یک reverse proxy با TLS قرار دهید یا دسترسی را با VPN/فایروال محدود کنید.

## کنترل کلاینت با اسکریپت (کانال کنترل)

کلاینت ویندوز یک کانال کنترل HTTP کوچک روی `127.0.0.1:17871` ارائه
می‌دهد تا بتوانید به‌جای کلیک دستی، با اسکریپت آن را کنترل کنید.
این کانال فقط روی لوپ‌بک گوش می‌دهد و هر درخواست باید توکن مشترک را
داشته باشد، پس هیچ چیز بیرون از این دستگاه به آن دسترسی ندارد.

توکن در نخستین اجرا ساخته می‌شود و در این مسیر ذخیره می‌گردد:

```
%AppData%\OpenMeshGaming\control_token.txt
```

دو اسکریپت آماده همراه کلاینت ارائه شده است:

```
control\omc.sh      # bash / Git-Bash
control\omc.ps1     # PowerShell
```

```bash
./control/omc.sh status              # وضعیت به‌صورت JSON
./control/omc.sh log                 # لاگ اخیر کلاینت
./control/omc.sh connect             # ورود به LAN گیمینگ
./control/omc.sh disconnect          # خروج از LAN گیمینگ
./control/omc.sh cancel              # لغو فرآیند اتصال در جریان
./control/omc.sh ping                # اجرای پینگ دستی
./control/omc.sh service             # روشن/خاموش کردن سرویس ZeroTier
./control/omc.sh settings server=192.168.31.96 port=8080 token=XXXX
./control/omc.sh quit                # بستن کلاینت
```

```powershell
.\control\omc.ps1 status
.\control\omc.ps1 connect
.\control\omc.ps1 log
```

### HTTP خام

```
GET  /status       وضعیت فعلی به‌صورت JSON
GET  /log          لاگ اخیر کلاینت
GET  /token        توکن کنترل
POST /connect      شروع فرآیند اتصال
POST /disconnect   قطع اتصال
POST /cancel       لغو اتصال در جریان
POST /ping         اجرای پینگ دستی
POST /service      روشن/خاموش کردن سرویس ZeroTier
POST /settings     تنظیم آدرس سرور / پورت / توکن bootstrap و ذخیره
POST /quit         بستن کلاینت
```

توکن را می‌توانید در هدر `X-OpenMesh-Control`، به‌صورت
`Authorization: Bearer <token>`، یا در پارامتر `?token=` بفرستید.

```bash
TOKEN=$(cat "$APPDATA/OpenMeshGaming/control_token.txt")
curl -s -H "X-OpenMesh-Control: $TOKEN" http://127.0.0.1:17871/status
```

پورت را می‌توان با متغیر محیطی `OPENMESH_CONTROL_PORT` تغییر داد.
